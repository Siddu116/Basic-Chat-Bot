# Basic Chatbot – Python

## Description
**Basic Chatbot** is a Python-based console application that interacts with the user through simple text-based conversations. The chatbot can respond to greetings, common questions, and basic commands. The main goal is to simulate a friendly conversation and provide relevant answers based on user input.

---

## Project Overview

The chatbot works by matching user input with predefined keywords and responses:
- The user types a message or question.
- The chatbot analyzes the input to detect keywords or intent.
- If a match is found, the chatbot returns a corresponding response.
- If no match is found, the chatbot gives a default fallback response.
- The conversation continues until the user types a termination command like bye or exit.

---

## Features
- Keyword-based text interaction
- Predefined responses for greetings, questions, and commands
- Case-insensitive input handling
- Default fallback response for unrecognized input
- Loop-based conversation until user ends the chat

---

## Tools & Technologies
- **Python** – Core programming language
- **String operations** – For input processing and matching keywords
